# 🎸 ChordAI

הפקת דף אקורדים מסודר — מילים ואקורדים — מכל שיר: קישור מיוטיוב, הקלטה מהמיקרופון,
או קובץ שמע. עם נגן שמדגיש את האקורד המתנגן, גרסת מובייל וגרסת הדפסה.

## מה זה עושה

1. מקבל קישור יוטיוב, הקלטה או קובץ.
2. מפריד את הקול מהכלים.
3. מזהה אקורדים מהנגינה, ומתמלל את המילים עם תזמון לכל מילה.
4. מרכיב דף אקורדים — כל אקורד מעל המילה שבה הוא מתנגן.

## התקנה

דרישות מוקדמות: **Node 18+**, **Python 3.11**, וכן `ffmpeg` ו-`yt-dlp`:

```bash
brew install ffmpeg yt-dlp
```

התקנת הפרויקט:

```bash
npm run setup
```

זה מתקין את חבילות הצד-שרת והצד-לקוח, יוצר סביבת פייתון ומתקין את ספריות הניתוח.
בפעם הראשונה שמנתחים שיר יורדים גם מודל התמלול ומודל ההפרדה (כמה GB, פעם אחת).

## הפעלה

```bash
npm run build && npm start
```

ואז לפתוח <http://localhost:5178>.

לפיתוח, עם רענון אוטומטי:

```bash
npm run dev
```

## הגדרות

מעתיקים את `.env.example` ל-`.env` ומשנים לפי הצורך. השניים המעניינים:

| הגדרה | ברירת מחדל | משמעות |
| --- | --- | --- |
| `CHORDAI_WHISPER_MODEL` | `large-v3` | דיוק התמלול. `small` מהיר, `large-v3` הכי מדויק בעברית. |
| `CHORDAI_SEPARATE` | `true` | הפרדת קול מכלים לפני הניתוח. משפר מאוד את שתי התוצאות. |

## איך משיגים מילים מדויקות

תמלול אוטומטי של שירה בעברית לא יהיה מושלם. לכן יש שני כלים בדף השיר:

- **הדבקת מילים** — מדביקים את המילים האמיתיות, והמערכת מסנכרנת אותן לאודיו
  ומציבה מחדש את האקורדים. שורה ריקה מפרידה בין בתים. זו הדרך להגיע לדיוק מלא.
- **עריכה** — לחיצה על מילה או אקורד מתקנת אותם במקום. `+` מוסיף אקורד, ומחיקת
  התוכן מסירה אותו. השינויים נשמרים לבד.

## שימוש בדף השיר

- **טרנספוזיציה וקאפו** — משנים את האקורדים המוצגים בלי לגעת באודיו.
- **גלילה אוטומטית** — הדף עוקב אחרי הנגינה.
- **הדפסה** — פריסה נקייה בשחור-לבן, בלי חיתוך שורות באמצע.
- **מהירות ניגון** — להאטה לצורך תרגול.
- מקש רווח מנגן ועוצר, וחיצים מדלגים חמש שניות.

## גישה מהאינטרנט

### הדרך המומלצת: מנהרה למחשב הזה
הניתוח כבד. המחשב הזה (M4 Pro) מסיים שיר בכדקה; שרת ענן זול יעשה את זה פי כמה
לאט יותר. לכן הכי פשוט להשאיר את העיבוד כאן ולפתוח מנהרה:

```bash
brew install cloudflared && cloudflared tunnel --url http://localhost:5178
```

מתקבלת כתובת `https://...trycloudflare.com` שעובדת מכל מקום, גם מהטלפון.
המחשב חייב להיות דלוק. אין עלות.

### שרת משלך (Docker)

```bash
docker build -t chordai . && docker run -p 5178:5178 -v chordai-data:/app/data chordai
```

בקונטיינר אין מעבד גרפי, ולכן ההפרדה רצה על CPU ואיטית בהרבה. מומלץ 8 ליבות ומעלה,
או `CHORDAI_SEPARATE=false`.

### ⚠️ לפני שפותחים את זה לציבור
- **אין אימות משתמשים.** כל מי שיש לו את הכתובת רואה ומוחק את כל השירים, ויכול
  למלא את הדיסק. חובה להוסיף התחברות והגבלת קצב לפני חשיפה ציבורית.
- **הורדת אודיו מיוטיוב מנוגדת לתנאי השימוש שלו.** לשימוש אישי זה עניין אחד;
  להפעיל שירות ציבורי שעושה את זה עבור כל אחד זו חשיפה משפטית ממשית. שירותים כאלה
  נסגרו בעבר. אם המטרה ציבורית — עדיף להשאיר רק העלאת קבצים שלמשתמש יש זכות עליהם.
- **קבצי השמע מוגני זכויות יוצרים** ומוגשים כאן כקבצים. הפצה פומבית שלהם מוסיפה
  חשיפה נוספת מעבר לעצם ההורדה.
