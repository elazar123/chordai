# ChordAI — תוסף אקורדים ליוטיוב

תיבה קטנה שמציגה את האקורדים של השיר שמתנגן, בזמן אמת.

## התקנה

1. פותחים בכרום: `chrome://extensions`
2. מדליקים **מצב מפתח** (Developer mode) בפינה הימנית העליונה
3. לוחצים **טען תוסף לא ארוז** (Load unpacked) ובוחרים את התיקייה הזו
4. פותחים שיר ביוטיוב — התיבה תופיע בפינה

## שימוש

- **גרירה** — אפשר לגרור את התיבה לכל מקום, והמיקום נשמר
- **+ / −** — טרנספוזיציה, להתאים לסולם שנוח לך לשיר בו
- **♪** — אקורדים פשוטים: מוריד סיומות כמו maj7 ומשאיר את המשולש
- **▾** — מכווץ את התיבה

## איך זה עובד

הזיהוי רץ **אצלך בדפדפן**. התוסף מאזין לאודיו של הלשונית, מפרק אותו לתדרים
(התמרת פורייה), בודק כמה אנרגיה יש בכל אחד מ-12 הצלילים, ומשווה לתבניות אקורדים.

זו מתמטיקה, לא בינה מלאכותית — ולכן זה רץ בזמן אמת ולא עולה כלום.
**שום דבר לא נשלח לשום שרת.** אין חשבון, אין הרשמה, אין תלות באף מחשב אחר.

## מגבלות

הזיהוי שומע את השיר תוך כדי ולא יכול "להסתכל קדימה" על השיר כולו, ואין הפרדה בין
הכלים לשירה. לכן הוא פחות מדויק מהניתוח המלא של ChordAI המקומי — במיוחד בשירים
עמוסים או עם הרבה כלי הקשה. לדיוק גבוה יותר, ולמילים מסונכרנות, יש את האפליקציה
המלאה בתיקייה הראשית.
